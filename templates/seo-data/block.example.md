# Human-only blockers

No human-only blockers.

`$operate-seo-site` defines the normal autonomous workflow. Add an item here only
when an external system truly requires a human-only action, required permission
does not exist, a legal or billing decision is required, or no safe rollback
path exists. Include the exact blocked action, evidence, impact, mitigation, and
minimal external action needed. Remove resolved items in the next pull request.
