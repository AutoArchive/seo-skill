# SEO operating-cycle launcher

Open the consuming website repository with the authorized connected tools and
invoke `$operate-seo-site` from
`.github/seo-skills/skills/operate-seo-site/SKILL.md`.

Read the repository instructions and its `.github/seo-data/daily-task.md` before
acting. Treat `daily-task.md` as the site's short, repository-specific checklist;
do not expect it to repeat the shared analytics, repair, pull-request,
deployment, or closeout workflow.

Run autonomously until `$operate-seo-site` reaches a truthful terminal outcome.
Do not schedule the agent through repository CI, cron, webhooks, hosted runners,
or model-provider credentials. Existing CI and deployment workflows may be used
for delivery and verification.
